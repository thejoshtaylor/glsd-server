1. Create `frontend/src/hooks/useVoiceRecorder.ts`:
   - Export type: `type RecorderState = 'idle' | 'recording' | 'processing'`
   - Export function: `useVoiceRecorder(onTranscript: (text: string) => void, onError: (error: string) => void)`
   - State: `state: RecorderState` (useState, default 'idle'), `elapsed: number` (useState, default 0)
   - Refs: `mediaRecorderRef: useRef<MediaRecorder | null>(null)`, `chunksRef: useRef<Blob[]>([])`, `timerRef: useRef<ReturnType<typeof setInterval> | null>(null)`, `streamRef: useRef<MediaStream | null>(null)`
   - Constant: `const MAX_DURATION_S = 60`
   - `start` callback (useCallback, deps: [onTranscript, onError]):
     a. Wrap entire body in try/catch. On `DOMException` with name `NotAllowedError`, call `onError("Microphone permission denied")` and return. On other errors, call `onError("Failed to start recording")` and return.
     b. `const stream = await navigator.mediaDevices.getUserMedia({ audio: true })`
     c. Store in streamRef: `streamRef.current = stream`
     d. Detect mimeType: `const mimeType = MediaRecorder.isTypeSupported('audio/webm;codecs=opus') ? 'audio/webm;codecs=opus' : 'audio/webm'`
     e. `const recorder = new MediaRecorder(stream, { mimeType })`
     f. `chunksRef.current = []`
     g. `recorder.ondataavailable = (e) => { if (e.data.size > 0) chunksRef.current.push(e.data) }`
     h. `recorder.onstop = async () => { ... }` — inside onstop:
        - Stop all tracks: `streamRef.current?.getTracks().forEach(t => t.stop()); streamRef.current = null`
        - `setState('processing')`
        - `const blob = new Blob(chunksRef.current, { type: mimeType })`
        - Call `sendForTranscription(blob, onTranscript, onError)` (defined below)
        - After sendForTranscription resolves (success or error), `setState('idle')` and `setElapsed(0)`
     i. `recorder.start(250)` — collect chunks every 250ms
     j. `mediaRecorderRef.current = recorder`
     k. `setState('recording')` and `setElapsed(0)`
     l. Start timer: `timerRef.current = setInterval(() => { setElapsed(prev => prev + 1) }, 1000)`
   - `stop` callback (useCallback, deps: []):
     a. If `timerRef.current`, `clearInterval(timerRef.current); timerRef.current = null`
     b. If `mediaRecorderRef.current && mediaRecorderRef.current.state !== 'inactive'`, call `mediaRecorderRef.current.stop()`
     c. `mediaRecorderRef.current = null`
   - Auto-stop effect: `useEffect(() => { if (elapsed >= MAX_DURATION_S) { stop() } }, [elapsed, stop])`
   - Cleanup effect: `useEffect(() => { return () => { stop(); streamRef.current?.getTracks().forEach(t => t.stop()) } }, [stop])`
   - Return: `{ state, elapsed, start, stop }`
   - Define `sendForTranscription` as a module-level async function (NOT inside the hook):
     ```typescript
     async function sendForTranscription(
       blob: Blob,
       onTranscript: (text: string) => void,
       onError: (error: string) => void,
     ): Promise<void> {
       try {
         const formData = new FormData()
         formData.append('file', blob, 'audio.webm')
         // Use raw fetch — NOT the api() helper — to avoid Content-Type header injection
         const { getAccessToken } = await import('@/lib/api')
         const token = getAccessToken()
         const res = await fetch('/api/transcribe', {
           method: 'POST',
           headers: token ? { Authorization: `Bearer ${token}` } : {},
           body: formData,
           // DO NOT set Content-Type — browser must set multipart boundary
         })
         if (!res.ok) {
           const text = await res.text()
           onError(text || 'Transcription failed')
           return
         }
         const data = await res.json()
         onTranscript(data.text)
       } catch {
         onError('Transcription failed. Try again.')
       }
     }
     ```
