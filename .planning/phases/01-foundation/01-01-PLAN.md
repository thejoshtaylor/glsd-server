**backend/app/config.py** — pydantic-settings `Settings` class (per DEPLOY-03):
- Fields: `database_url: str`, `jwt_secret_key: str`, `jwt_algorithm: str = "HS256"`, `jwt_access_token_expire_minutes: int = 30`, `server_token: str`, `openai_api_key: str`, `db_pool_size: int = 10`, `db_max_overflow: int = 20`

**backend/app/database.py** — Async engine and session factory:
- `from app.config import get_settings`
- `Base` class extending `DeclarativeBase`
- Do NOT create engine at module import time (causes import-time Settings validation failure when no .env exists). Instead use a lazy initialization pattern:
  - `_engine = None` and `_async_session_maker = None` at module level
  - `def get_engine()` that creates engine on first call using `get_settings().database_url`, `pool_size=get_settings().db_pool_size`, `max_overflow=get_settings().db_max_overflow`, `pool_pre_ping=True`
  - `def get_session_maker()` that creates `async_sessionmaker(get_engine(), class_=AsyncSession, expire_on_commit=False)` on first call
- Export `Base`, `get_engine`, `get_session_maker`

**backend/app/dependencies.py** — FastAPI dependencies:
- `async def get_db() -> AsyncGenerator[AsyncSession, None]` — acquires session from `get_session_maker()`, yields it, commits on success, rollbacks on exception
- `DbSession = Annotated[AsyncSession, Depends(get_db)]`

**backend/app/main.py** — FastAPI app with lifespan:
- `@asynccontextmanager async def lifespan(app: FastAPI)` — yields, then disposes engine via `get_engine().dispose()` on shutdown
- `app = FastAPI(title="GLSD Server", lifespan=lifespan)`

- `class NodeStatus(str, enum.Enum)`: `connected`, `stale`, `disconnected`
- `class Node(Base)` with `__tablename__ = "nodes"`:
  - `node_id: Mapped[str] = mapped_column(String(255), primary_key=True)` — stable hardware-derived ID
  - `platform: Mapped[str] = mapped_column(String(64))` — OS identifier
  - `version: Mapped[str] = mapped_column(String(32))` — node software version
  - `projects: Mapped[Optional[dict]] = mapped_column(JSON, nullable=True, default=list)` — use JSON instead of ARRAY for Alembic autogenerate compatibility (stores string list)
  - `team_id: Mapped[Optional[str]] = mapped_column(String(36), ForeignKey("teams.team_id"), nullable=True)`
  - `status: Mapped[NodeStatus] = mapped_column(SAEnum(NodeStatus, name="node_status", create_constraint=True), default=NodeStatus.disconnected)`
  - `first_seen: Mapped[datetime] = mapped_column(server_default=func.now())`
  - `connected_at: Mapped[Optional[datetime]] = mapped_column(nullable=True)`
