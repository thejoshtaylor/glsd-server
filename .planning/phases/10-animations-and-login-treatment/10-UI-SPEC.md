## Animation Contract

All animations are CSS `@keyframes` only. No motion library. No direct `box-shadow` animation (causes repaints — STATE.md locked constraint).

### Keyframes to Define in `index.css`

| Name | Target Element | Duration | Easing | Loop | Trigger |
|------|---------------|----------|--------|------|---------|
| `glowPulse` | `::after` pseudo-element opacity | 2s | ease-in-out | infinite | `.pulse-glow-cyan` class on NodeCard when `node.status === 'connected'` |
| `liveDotPulse` | `.live-dot` span opacity | 1.5s | ease-in-out | infinite | `{isRunning && <span className="live-dot" />}` in StreamPanel |
| `pulseRing` | `::after` pseudo-element scale + opacity | 1s | ease-out | infinite | `.pulse-ring-magenta` class on VoiceButton when `state === 'recording'` |
| `glitch` | Login card `transform` + `text-shadow` | 300ms | linear | once (forwards) | `.glitch-once` class toggled by JS after login API success |

Page fade-in uses **tw-animate-css** built-ins — no custom keyframe needed:
- Class: `animate-in fade-in duration-150 fill-mode-both`
- Applied to: outermost `<div>` of each route component root (not the Outlet wrapper — see pitfall in RESEARCH.md)

### Exact `@keyframes` Values

**`glowPulse`** (ANI-01 — NodeCard connected state):
```css
@keyframes glowPulse {
  0%, 100% { opacity: 0.3; }
  50%       { opacity: 1.0; }
}
```
Box-shadow value on the `::after`: `0 0 10px 3px oklch(0.75 0.18 195 / 70%)`
Extend existing `.glow-cyan` structural pattern (`position: relative; isolation: isolate; ::after { inset: -2px; border-radius: inherit; z-index: -1; pointer-events: none }`) — replace `transition` with `animation: glowPulse 2s ease-in-out infinite`.

**`liveDotPulse`** (ANI-02 — Stream live dot):
```css
@keyframes liveDotPulse {
  0%, 100% { opacity: 0.4; }
  50%       { opacity: 1.0; }
}
```
Dot dimensions: 6×6px, `border-radius: 9999px`, `background: oklch(0.75 0.18 195)`, `display: inline-block`, `vertical-align: middle`.

**`pulseRing`** (ANI-03 — VoiceButton recording):
```css
@keyframes pulseRing {
  0%   { transform: scale(1);    opacity: 1; }
  100% { transform: scale(1.15); opacity: 0; }
}
```
`::after` properties: `inset: -4px`, `border-radius: 9999px`, `border: 2px solid oklch(0.70 0.25 330 / 80%)`.

**`glitch`** (LGN-04 — Login success animation):
```css
@keyframes glitch {
  0%   { transform: translateX(0);    text-shadow: none; }
  20%  { transform: translateX(-4px); text-shadow: -3px 0 oklch(0.65 0.22 25), 3px 0 oklch(0.75 0.18 195); }
  40%  { transform: translateX(4px);  text-shadow: 3px 0 oklch(0.65 0.22 25), -3px 0 oklch(0.75 0.18 195); }
  60%  { transform: translateX(-2px); text-shadow: -2px 0 oklch(0.65 0.22 25); }
  80%  { transform: translateX(2px);  text-shadow: 2px 0 oklch(0.75 0.18 195); }
  100% { transform: translateX(0);    text-shadow: none; }
}
```
Applied via `.glitch-once { animation: glitch 300ms linear 1 forwards; }` on the login Card or its outer wrapper.

### Reduced Motion

Single block at the **very end** of `index.css` (after all `@layer utilities` and `@keyframes` declarations):

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}
```

JS glitch trigger must also check: `window.matchMedia('(prefers-reduced-motion: reduce)').matches` — if true, navigate immediately without class toggle or setTimeout.

Source: CONTEXT.md locked decision; RESEARCH.md Pitfall 3 (placement); ANI-05.

## Login Page Design Contract

### LGN-01 — Grid Background

Applied to the login page full-screen wrapper div:

```css
background-image:
  repeating-linear-gradient(
    0deg,
    oklch(0.75 0.18 195 / 5%) 0px,
    oklch(0.75 0.18 195 / 5%) 1px,
    transparent 1px,
    transparent 40px
  ),
  repeating-linear-gradient(
    90deg,
    oklch(0.75 0.18 195 / 5%) 0px,
    oklch(0.75 0.18 195 / 5%) 1px,
    transparent 1px,
    transparent 40px
  );
```

Grid line thickness: 1px. Grid cell spacing: 40px. Opacity: 5%. Both values per RESEARCH.md code examples (Claude's discretion confirmed).

### LGN-02 — Gradient Card Border

**Use gradient wrapper div technique — NOT `border-image`** (border-image breaks border-radius).

```css
.login-card-border {
  border-radius: var(--radius);   /* 0.625rem — matches card radius */
  padding: 1px;
  background: linear-gradient(135deg, oklch(0.75 0.18 195), oklch(0.70 0.25 330));
}
```

The inner shadcn `<Card>` must override `ring-1` to `ring-0` and `border-0` to prevent the default ring showing through the gradient wrapper.

Source: RESEARCH.md Pattern 5 — confirmed technique for shadcn Card which uses `ring-*` not `border`.

### LGN-03 — Neon Title Glow

Applied to the login `<CardTitle>` element using Orbitron font at 28px/700:

```css
text-shadow:
  0 0 10px oklch(0.75 0.18 195),
  0 0 20px oklch(0.75 0.18 195 / 70%),
  0 0 40px oklch(0.75 0.18 195 / 40%);
```

Inline style or CSS class. Orbitron font-family already loaded via `font-heading` utility class.

### LGN-04 — Glitch on Login Success

Trigger sequence in `handleSubmit` after `setTokens()`:

1. Check `window.matchMedia('(prefers-reduced-motion: reduce)').matches`
2. If false: add `glitch-once` class to the card container, `setTimeout(() => navigate(...), 300)`
3. If true: navigate immediately, no class toggle
4. Store setTimeout ref in `useRef`; clear in `useEffect` cleanup to prevent state-on-unmounted-component errors

## Anti-Patterns (Executor Must Avoid)

| Anti-Pattern | Why | What to Do Instead |
|-------------|-----|-------------------|
| `animation: box-shadow ...` directly | Causes GPU repaint every frame | Animate `::after` pseudo-element `opacity` on a static `box-shadow` |
| `border-image` on the login card | Overrides `border-radius`, corners go square | Use `.login-card-border` wrapper div (padding: 1px, gradient background) |
| `animate-in fade-in` on the Outlet wrapper in `__root.tsx` | Div stays mounted across routes; animation only fires once | Apply `animate-in fade-in duration-150 fill-mode-both` to each route component's root div |
| `@keyframes` inside `@theme inline {}` | Triggers OKLCH dark mode bug #18296 | Define keyframes at top-level in `index.css`, outside any `@theme` block |
| `@media (prefers-reduced-motion: reduce)` placed before keyframes | Later animation rules override it | Place reduced-motion block as the very last rule in `index.css` |
| `animate-in fade-in` on `StreamEventRenderer` rows | Queues at >5 events/sec, causes visual jitter | Never animate stream row mounts — STATE.md locked constraint |
| Navigating immediately without `setTimeout` during glitch | Glitch animation gets cut short | Wait 300ms after adding `.glitch-once` class before navigating |
| Not checking `prefers-reduced-motion` in JS glitch handler | Animation fires on accessibility users | Check `window.matchMedia(...)` before any class toggle or setTimeout |
