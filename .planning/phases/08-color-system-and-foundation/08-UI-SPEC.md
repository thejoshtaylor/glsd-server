- Timestamps
- Stream/command output text

### Accent Reserved For

Neon magenta (`--accent`, `oklch(0.70 0.25 330)`) is reserved **exclusively** for:
- Voice recording indicator state (Phase 10 use — token established here)
- Accent badges and decorative labels that must contrast against cyan-dominant UI
- Secondary/ghost button hover states that need magenta differentiation

Neon cyan (`--primary`, `oklch(0.75 0.18 195)`) is the primary interactive color, used for:
- All default buttons (shadcn `Button` default variant)
- All focus rings (via `--ring`)
- All borders (via `--border` at 15% opacity)
- Scroll-to-bottom FAB (established here, applied in Phase 9)

Destructive (`oklch(0.65 0.22 25)`) is reserved **exclusively** for:
- Kill/terminate instance actions
- Delete confirmation dialogs

## Glow Utility Contract

Source: CONTEXT.md locked decisions + STATE.md pitfall avoidance.

### Technique

Pseudo-element `::after` with `opacity` transition. Static `box-shadow` on the pseudo-element, animated via `opacity: 0 → 1`. This avoids GPU repaint from animating `box-shadow` directly.

### Utility Classes

| Class | Effect | Reserved For |
|-------|--------|-------------|
| `glow-cyan` | 8px spread cyan halo, 60% opacity, 200ms ease-out | Primary buttons, focus-visible elements |
| `glow-magenta` | 8px spread magenta halo, 60% opacity, 200ms ease-out | Accent interactive elements (Phase 9/10 expansion) |

### Phase 8 Application Scope

- `glow-cyan` applied to: shadcn `Button` default variant source (`src/components/ui/button.tsx`)
- `glow-cyan` applied to: global focus ring styles via `@layer base`
- `glow-magenta` available as utility class — not applied to specific components in Phase 8

### CSS Implementation

```css
@layer utilities {
    .glow-cyan {
        position: relative;
        isolation: isolate;
    }
    .glow-cyan::after {
        content: '';
        position: absolute;
        inset: -2px;
        border-radius: inherit;
        background: transparent;
        box-shadow: 0 0 8px 2px oklch(0.75 0.18 195 / 60%);
        opacity: 0;
        transition: opacity 200ms ease-out;
        pointer-events: none;
        z-index: -1;
    }
    .glow-cyan:hover::after,
    .glow-cyan:focus-visible::after {
        opacity: 1;
    }

    .glow-magenta {
        position: relative;
        isolation: isolate;
    }
    .glow-magenta::after {
        content: '';
        position: absolute;
        inset: -2px;
        border-radius: inherit;
        background: transparent;
        box-shadow: 0 0 8px 2px oklch(0.70 0.25 330 / 60%);
        opacity: 0;
        transition: opacity 200ms ease-out;
        pointer-events: none;
        z-index: -1;
    }
    .glow-magenta:hover::after,
    .glow-magenta:focus-visible::after {
        opacity: 1;
    }
}
```

### Token Architecture Rule (LOCKED)

OKLCH values: `.dark { }` block **only**.
`@theme inline`: CSS variable references (`var(--token-name)`) **only**.
Never put raw OKLCH values inside `@theme inline` — Tailwind v4 bakes them as static values (bug #18296).
