5. `async def run_sequence(seq: ActiveSequence) -> None` coroutine:
   - Import `dispatch_execute` from `app.ws.commands`
   - Import `frontend_manager` from `app.ws.frontend_manager`
   - Import `get_session_maker` from `app.database`
   - For each step in `seq.steps`:
     - Set `seq.current_step = i`
     - Call `await frontend_manager.broadcast_sequence_step(seq.sequence_id, seq.node_id, seq.user_id, step_index=i, total_steps=len(seq.steps), command_id=step["command_id"], status="started", auto_advance=seq.auto_advance)`
     - Dispatch `/clear` first: acquire fresh session via `async with get_session_maker()() as db:`, call `dispatch_execute(node_id=seq.node_id, project=seq.project, work_dir=seq.work_dir, prompt="/clear", user_id=seq.user_id, db=db)`, register the returned instance_id with `sequence_registry.register_instance()`, await the event, then call `cleanup_instance()` immediately after
     - Dispatch the actual command: `expand_prompt(step["command_id"], step.get("params", {}))`, same dispatch+wait+cleanup pattern
     - Call `await frontend_manager.broadcast_sequence_step(...)` with status="completed" and auto_advance=seq.auto_advance
     - If `not seq.auto_advance and i < len(seq.steps) - 1`: clear `seq.advance_event`, then `await seq.advance_event.wait()`
   - After all steps: `await frontend_manager.broadcast_sequence_done(seq.sequence_id, seq.node_id, seq.user_id)`
   - `except asyncio.CancelledError`: broadcast sequence_error with reason="cancelled", then re-raise
   - `except Exception as exc`: broadcast sequence_error with reason=str(exc)
   - `finally`: call `sequence_registry.remove(seq.node_id, seq.sequence_id)`

**CRITICAL anti-patterns to avoid (from STATE.md and RESEARCH.md):**
- Do NOT hold a DB session across the sequence loop -- each dispatch_execute gets its own `async with get_session_maker()() as db:` wrapper
- ALWAYS call `cleanup_instance()` after `await event.wait()` returns -- prevents memory leak
- Signal completion for BOTH finished and errored outcomes
- Spawn run_sequence as independent `asyncio.Task` (done in frontend_router, not here)

Then extend `backend/app/ws/frontend_manager.py` with three new broadcast methods on `FrontendConnectionManager`:

7. `async def broadcast_sequence_done(self, sequence_id, node_id, user_id)`:
   - Msg: `{"type": "sequence_done", "sequence_id": sequence_id, "node_id": node_id}`
   - Fan out to ALL connections

8. `async def broadcast_sequence_error(self, sequence_id, node_id, user_id, *, reason)`:
