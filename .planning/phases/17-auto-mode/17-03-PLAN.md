3. **Create `frontend/src/components/execute/SequenceBuilder.tsx`:**
   ```
   Props: { nodeId: string; project: string; workDir: string }
   ```
   - Local state:
     - `selectedPreset: string | null` (preset id or null for custom)
     - `steps: Array<{ command_id: string; params: Record<string, string> }>` (the queue)
     - `showCustomBuilder: boolean`
   - Read `socket` from `useWsStore`, `autoModeNodeIds` from `useWsStore`
   - Derive `autoAdvance = autoModeNodeIds.includes(nodeId)`
   - **Preset selector section:**
     - Render `GSD_SEQUENCE_PRESETS` as clickable cards/buttons, each showing label + description
     - On preset click: set `steps` to preset's steps array (expanding `default_params` if present), clear `selectedPreset` if re-clicking same
     - When a preset step has params (check `GSD_COMMANDS.find(c => c.id === step.command_id)?.params`), show inline Input fields for each required param in the step list
   - **Custom builder section:**
     - "Add Step" button that shows a dropdown/list of all `GSD_COMMANDS` to pick from
     - Each step in the queue shows: step number, command label, remove button (Trash2 icon), move up button (ArrowUp icon)
     - If the command has params, show inline Input fields
   - **Start button:**
     - Disabled until: `steps.length > 0` AND all required params filled for every step AND `project` is truthy AND socket is connected
     - Param validation: for each step, find command in `GSD_COMMANDS`, check all `required` params have non-empty values
     - On click: send WS message `{ type: 'start_sequence', node_id: nodeId, project, work_dir: workDir, steps, auto_advance: autoAdvance }`
     - After sending, clear local steps state
   - **Cancel button** (shown only when a sequence for this node exists in `sequenceStates`):
     - Find active sequence: `Object.values(sequenceStates).find(s => s.node_id === nodeId && (s.status === 'running' || s.status === 'paused'))`
     - On click: send `{ type: 'cancel_sequence', sequence_id: seq.sequence_id }`
   - Style: consistent with CommandPalette -- `space-y-3`, `text-sm`, same border/bg patterns
   - Only render the builder when auto mode is enabled for this node (check `autoModeNodeIds.includes(nodeId)`)

4. **Create `frontend/src/components/execute/SequenceProgress.tsx`:**
   ```
   Props: { nodeId: string }
   ```
   - Read `sequenceStates` from `useWsStore`, `socket` from `useWsStore`, `clearSequenceState` from `useWsStore`
   - Find sequence for this node: `Object.values(sequenceStates).find(s => s.node_id === nodeId)` -- show the most recent one (running > paused > done/error)
   - If no sequence found, render nothing (return null)
   - Render a card with:
     - Header: "Sequence Progress" with status badge (running=Activity icon green, paused=Clock icon yellow, done=CheckCircle icon green, error=AlertTriangle icon red)
     - Step list: for `i` from 0 to `total_steps - 1`:
       - Completed steps (i < current_step when running, or i <= current_step when done): CheckCircle icon, text-muted-foreground, strikethrough on command label
       - Active step (i === current_step and status === 'running'): CircleDot icon, text-primary, pulsing dot or highlight
       - Pending steps (i > current_step): Clock icon, text-muted-foreground/50
       - Each step shows step number and command_id (look up label from GSD_COMMANDS if found)
     - When status === 'paused': show "Advance" button (SkipForward icon) that sends `{ type: 'advance_sequence', sequence_id: seq.sequence_id }`
     - When status === 'done': show "Dismiss" button that calls `clearSequenceState(seq.sequence_id)`
     - When status === 'error': show error reason text and "Dismiss" button
   - Style: `p-4 bg-muted/50 rounded-lg border border-border`, step list uses `space-y-1`
