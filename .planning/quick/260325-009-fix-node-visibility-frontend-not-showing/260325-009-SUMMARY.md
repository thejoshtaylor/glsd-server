# Quick Task 260325-009: Fix Node Visibility (Frontend Not Showing Reconnecting Nodes)

**One-liner:** Moved NodeTeam auto-assignment to run unconditionally after every node upsert so reconnecting nodes without a NodeTeam row get assigned and become visible via `list_nodes_for_user` JOIN.

---

## Problem

`handle_node_register()` in `handlers.py` only created a `NodeTeam` row inside the `if node is None:` branch (new node path). Reconnecting nodes — and nodes registered before auto-assignment was introduced — had no `NodeTeam` row. The `list_nodes_for_user()` query in `node_service.py` inner-joins through `NodeTeam`, so those nodes were silently filtered out and never appeared in the frontend node list.

---

## Solution

Refactored `handle_node_register()` to:

1. Keep `session.flush()` inside the `if node is None:` branch so the `Node` FK row exists before any FK insert.
2. Remove the `NodeTeam` creation from the new-node branch.
3. Add an unconditional `NodeTeam` existence check **after both branches** — if no `NodeTeam` row exists for the node (new or reconnecting), auto-assign to the first team.
