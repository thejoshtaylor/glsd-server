   - `initial_admin_password: str | None = None`
   Place them in a new comment section `# Initial admin bootstrap (optional)` after the DB pool section.

2. Create `backend/app/services/admin_bootstrap.py` with an `async def ensure_initial_admin(settings: Settings) -> None` function:
   - If `settings.initial_admin_email` is None or `settings.initial_admin_password` is None, return immediately (no-op).
   - Get a session from `get_session_maker()`.
   - Inside `async with session_maker() as session:` and `async with session.begin():`:
     - Query `select(User).where(User.email == settings.initial_admin_email)`.
     - If user exists, log "Initial admin user already exists, skipping" and return.
     - If not, create User with `user_id=str(uuid.uuid4())`, email from settings, hashed_password via `auth_service.hash_password()`.
     - Also create Team and TeamMember (same pattern as `register_user` in auth_service.py) for consistency.
     - Log "Created initial admin user: {email}".
   - Use `import logging; logger = logging.getLogger(__name__)` for log messages.
   - Do NOT reuse `register_user()` directly because it raises HTTPException and returns TokenResponse — neither appropriate for startup bootstrap. Replicate the user+team+membership creation logic inline.

3. In `backend/app/main.py` — in the `lifespan` function, after the `scanner_task` line and before `yield`:
   - Import and call: `from app.services.admin_bootstrap import ensure_initial_admin`
   - Add: `settings = get_settings()` (import `get_settings` from `app.config`)
   - Add: `await ensure_initial_admin(settings)`
