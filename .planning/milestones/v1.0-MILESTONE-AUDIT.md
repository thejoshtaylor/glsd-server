### Integration Issues Found

**INT-01 (High): WebSocket reconnect does not refresh expired access tokens**

- **Location:** `frontend/src/hooks/useWebSocket.ts` lines 24-28
- **Issue:** Raw `fetch('/api/auth/ws-ticket')` bypasses the `api()` wrapper's 401-retry-with-refresh logic. After access token expiry (~30 min), WS reconnect silently fails.
- **Impact:** Dashboard shows stale data until user hard-reloads or navigates
- **Fix:** Use `api()` or import `refreshAccessToken()` and retry on 401
- **Affected:** DASH-01, STRM-01, NODE-01, NODE-09, AUTH-03

**INT-02 (Low): Audit page does not establish WebSocket connection**

- **Location:** `frontend/src/routes/dashboard/audit.tsx`
- **Issue:** Direct navigation to `/dashboard/audit` (bookmark) skips `useWebSocket()`. REST audit data loads correctly; only live updates missing.
- **Fix:** Hoist `useWebSocket()` to `dashboard/route.tsx` layout component
- **Affected:** DASH-01 (partial), STRM-01 (partial)
