Purpose: Users can background the app, return after token expiry, and get live WS data without manual refresh. Users can bookmark /dashboard/audit and get live events immediately.

Output: Modified backend WS handler with auth-specific close code, updated useWebSocket hook with token refresh on auth failure, layout-level WS connection serving all dashboard routes.
</objective>

    ```typescript
    async function connect() {
      let accessToken = getAccessToken()
      if (!accessToken) {
        // No token at all — try refreshing (e.g., returning to backgrounded tab)
        const refreshed = await refreshAccessToken()
        if (!refreshed) return
        accessToken = getAccessToken()
        if (!accessToken) return
      }
    ```

    ```typescript
    const res = await fetch('/api/auth/ws-ticket', {
      method: 'POST',
      headers: { Authorization: `Bearer ${getAccessToken()}` },
    })
    if (res.status === 401) {
      const refreshed = await refreshAccessToken()
      if (!refreshed || unmounted) return
      // Retry ticket fetch with fresh token — call getAccessToken() AFTER refresh
      const retryRes = await fetch('/api/auth/ws-ticket', {
        method: 'POST',
        headers: { Authorization: `Bearer ${getAccessToken()}` },
      })
      if (!retryRes.ok) return
      const { ticket } = await retryRes.json()
      // ... proceed to open WS with this ticket (extract WS open into helper or inline)
    }
    if (!res.ok) return
    ```
    To avoid duplication, extract the "open WebSocket with ticket" logic into a local `openSocket(ticket: string)` helper inside the `connect` function. This helper creates the WebSocket, sets onopen/onmessage/onclose handlers, and stores in wsRef.

    d) In `ws.onclose`, detect close code 4001 and refresh before reconnecting:
    ```typescript
    ws.onclose = (event) => {
      if (unmounted) return
      setSocket(null)
      setConnected(false)
      wsRef.current = null

      if (event.code === 4001) {
        // Auth failure — refresh token and reconnect immediately (no backoff)
        refreshAccessToken().then((ok) => {
          if (!unmounted && ok) {
            reconnectAttempt.current = 0
            reconnectTimeout.current = setTimeout(connect, 500)
          }
        })
        return
      }

      // Normal close — exponential backoff
      const delay = Math.min(
        RECONNECT_DELAY_MS * Math.pow(2, reconnectAttempt.current),
        MAX_RECONNECT_DELAY_MS
      )
      reconnectAttempt.current++
      reconnectTimeout.current = setTimeout(connect, delay)
    }
    ```

    Keep the existing catch block for network errors during ticket fetch, and keep the existing RECONNECT_DELAY_MS (3000) and MAX_RECONNECT_DELAY_MS (30000) constants.
