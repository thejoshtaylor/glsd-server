## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline badge padding |
| sm | 8px | Compact element spacing, button icon gap |
| md | 16px | Default element spacing, card inner padding |
| lg | 24px | Section padding, step card vertical gap |
| xl | 32px | Layout column gaps, page section breaks |
| 2xl | 48px | Major section breaks between page sections |
| 3xl | 64px | Top-level page padding |

Exceptions: Touch targets for copy buttons — minimum 44px height to meet WCAG 2.5.5.

## Typography

| Role | Size | Weight | Line Height | Font | Notes |
|------|------|--------|-------------|------|-------|
| Body | 14px | 400 | 1.5 | Geist Variable (font-sans) | Default prose, helper text, field descriptions |
| Label | 14px | 600 | 1.4 | Geist Variable (font-sans) | Form field labels, nav items, badge text |
| Heading | 20px | 600 | 1.2 | Orbitron Variable (font-heading) | Page section headings (matches `text-xl font-semibold font-heading` pattern in codebase) |

Source: body/label sizes from existing dashboard patterns (`text-sm` = 14px used throughout). Heading size from `text-xl font-semibold font-heading` in audit.tsx and $nodeId.tsx. Display size is discretion default for onboarding hero.

## Color

All values are OKLCH. Tokens are from `.dark` block in `src/index.css` (dark mode is the primary application mode per cyberpunk design system).

| Role | OKLCH Token | Raw Value | Usage |
|------|-------------|-----------|-------|
| Dominant (60%) | `--background` | `oklch(0.10 0.01 250)` | Page background, full-bleed surfaces |
| Secondary (30%) | `--card` / `--sidebar` | `oklch(0.14 0.01 250)` / `oklch(0.12 0.01 250)` | Step cards, execute form card, nav sidebar |
| Accent (10%) — Cyan | `--primary` | `oklch(0.75 0.18 195)` | Copy button hover glow, step number badges, onboarding nav link active state, form focus rings |
| Accent (10%) — Magenta | `--accent` | `oklch(0.70 0.25 330)` | No new usage in Phase 13 — reserved for voice/recording interactions only |
| Destructive | `--destructive` | `oklch(0.65 0.22 25)` | No destructive actions in Phase 13 |

Accent reserved for:
- Step number badges on onboarding cards
- Copy button icon color (default state: `text-primary`)
- Copy button glow on hover (`.glow-cyan` utility)
- "Getting Started" nav link active/hover indicator
- Execute form Select focus ring (`--ring` = `oklch(0.75 0.18 195)`)

Muted text for helper copy: `--muted-foreground` = `oklch(0.60 0.04 195)`.

Code block background: `--muted` = `oklch(0.18 0.01 250)`, monospace text in `--foreground` = `oklch(0.92 0.02 195)`.

## Onboarding Page Layout

Route: `/dashboard/onboarding`

```
[Page: /dashboard/onboarding]
  DisplayHeading: "Getting Started"          ← Orbitron 28px/600
  SubText: "Connect your first GSD node..."  ← Geist 14px/400 muted-foreground

  [StepCard 1]  ← Card component, border oklch(0.75 0.18 195 / 15%)
    Badge: "1"  ← cyan bg, dark text, 20px circle
    Title: "Install GSD CLI"
    CodeBlock: "npm install -g @gsd/cli"  ← CopyButton top-right

  [StepCard 2]
    Badge: "2"
    Title: "Configure Your Node"
    CodeBlock: "gsd node configure --server https://... --token ..."
    (server URL and token are static placeholder strings)

  [StepCard 3]
    Badge: "3"
    Title: "Start Your Node"
    CodeBlock: "gsd node start"
```

Step cards stack vertically with 24px gap. Each card uses 16px inner padding. Code blocks inside cards use `--muted` background, `--foreground` text, `font-mono`, 14px, padding 12px 16px, `border-radius: var(--radius-md)`.

| Component | Default | Hover | Focus | Active | Disabled |
|-----------|---------|-------|-------|--------|---------|
| Copy button | Ghost, `text-muted-foreground` | `.glow-cyan` pseudo-element, `text-primary` | Focus ring `--ring` | Briefly shows checkmark icon, then reverts | n/a |

## Accessibility

- All copy buttons must have `aria-label="Copy command"` (screen reader text since button contains icon only).
- Step number badges must use `aria-hidden="true"` — step context is conveyed by the heading text.
- Advanced disclosure: if using `<details>`/`<summary>`, semantic HTML provides keyboard accessibility natively. If using shadcn Collapsible, ensure `aria-expanded` is set.
- Preset Select: after selection auto-populates textarea, focus must remain on Select (do not force focus to textarea).
- Color contrast: `--muted-foreground` (`oklch(0.60 0.04 195)`) on `--background` (`oklch(0.10 0.01 250)`) meets WCAG AA for 14px text (contrast ratio approximately 5.8:1).
- Reduced motion: `@media (prefers-reduced-motion: reduce)` block in `index.css` already disables all animations — copy button icon swap is state-based, not animation-based, so it is unaffected.
