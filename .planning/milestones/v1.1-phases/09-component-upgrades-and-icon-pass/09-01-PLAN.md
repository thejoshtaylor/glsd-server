**1a. Add glow-amber and glow-red utilities to index.css**

Open `frontend/src/index.css` and append two new utility classes inside the existing `@layer utilities` block, directly after the `.glow-magenta:hover::after, .glow-magenta:focus-visible::after` closing brace.

Follow the EXACT same pseudo-element pattern as glow-cyan and glow-magenta (position:relative, isolation:isolate, ::after pseudo with opacity transition, hover/focus-visible triggers). The only differences are the OKLCH color values:

For `.glow-amber`: box-shadow color = `oklch(0.75 0.15 85 / 60%)`
For `.glow-red`: box-shadow color = `oklch(0.65 0.22 25 / 60%)`

Full CSS for both utilities (copy the glow-cyan pattern exactly, only changing the box-shadow OKLCH value):

```css
.glow-amber {
    position: relative;
    isolation: isolate;
}
.glow-amber::after {
    content: '';
    position: absolute;
    inset: -2px;
    border-radius: inherit;
    background: transparent;
    box-shadow: 0 0 8px 2px oklch(0.75 0.15 85 / 60%);
    opacity: 0;
    transition: opacity 200ms ease-out;
    pointer-events: none;
    z-index: -1;
}
.glow-amber:hover::after,
.glow-amber:focus-visible::after {
    opacity: 1;
}

.glow-red {
    position: relative;
    isolation: isolate;
}
.glow-red::after {
    content: '';
    position: absolute;
    inset: -2px;
    border-radius: inherit;
    background: transparent;
    box-shadow: 0 0 8px 2px oklch(0.65 0.22 25 / 60%);
    opacity: 0;
    transition: opacity 200ms ease-out;
    pointer-events: none;
    z-index: -1;
}
.glow-red:hover::after,
.glow-red:focus-visible::after {
    opacity: 1;
}
```

IMPORTANT: Add these inside `@layer utilities { ... }`, NOT in `@theme inline` (per STATE.md locked decision).
