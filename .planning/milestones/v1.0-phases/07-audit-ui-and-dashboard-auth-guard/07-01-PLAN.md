**1. Create `frontend/src/routes/dashboard/route.tsx`** — TanStack Router layout route with `beforeLoad` auth guard.

This file acts as a layout route for ALL `/dashboard/*` child routes. TanStack Router file-based routing uses `route.tsx` as the layout for a directory.

```tsx
import { createFileRoute, Outlet, redirect } from '@tanstack/react-router'
import { getAccessToken } from '@/lib/api'

export const Route = createFileRoute('/dashboard')({
  beforeLoad: ({ location }) => {
    if (!getAccessToken()) {
      throw redirect({
        to: '/login',
        search: { redirect: location.href },
      })
    }
  },
  component: DashboardLayout,
})

function DashboardLayout() {
  return <Outlet />
}
```

This guard runs before any dashboard child route renders. If no access token exists, the user is redirected to `/login?redirect=<original_url>`.

**2. Update `frontend/src/routes/login.tsx`** — After successful login, redirect to the `redirect` search param if present, otherwise `/dashboard`.

Add search param validation to the route definition and use it after login:

- Add `validateSearch` to the route config to parse `{ redirect?: string }` from URL search params
- In `LoginPage`, use `Route.useSearch()` to get the redirect param
- Change line 44 from `navigate({ to: '/dashboard' })` to:
  ```tsx
  const search = Route.useSearch()
  // ... in handleSubmit after setTokens:
  const target = search.redirect || '/dashboard'
  navigate({ to: target })
  ```

The full route definition becomes:
```tsx
export const Route = createFileRoute('/login')({
  validateSearch: (search: Record<string, unknown>) => ({
    redirect: (search.redirect as string) || undefined,
  }),
  component: LoginPage,
})
```

And in the component, add `const search = Route.useSearch()` near the top, and replace `navigate({ to: '/dashboard' })` with `navigate({ to: search.redirect || '/dashboard' })`.

**3. Update `frontend/src/lib/api.ts`** — Add 401 interceptor that clears tokens and redirects to login.

The existing `api()` function already attempts refresh on 401 (lines 48-54). If refresh fails, it throws an error. Add a final 401 check after the refresh attempt fails:

After line 54 (the closing `}` of the refresh block), and before the `if (!res.ok)` check on line 56, add:

```typescript
if (res.status === 401) {
  clearTokens()
  window.location.href = '/login'
  throw new Error('Session expired')
}
```

This ensures that when both the original request AND the refresh attempt fail with 401, tokens are cleared and the user is redirected to login. Using `window.location.href` instead of TanStack Router navigate avoids importing router dependencies into the API utility.

**4. Add `AuditLogResponse` type to `frontend/src/types/api.ts`** — Add the TypeScript type matching the backend schema for use in Plan 02.
