**1. `async def handle_node_register(payload: NodeRegisterPayload, conn: NodeConnection) -> None`**
This is the most complex handler — it handles both first-connect and reconnect with reconciliation.

Steps:
a) Acquire the per-node lock: `async with connection_manager.get_lock(payload.node_id):`
b) Check if there's an existing connection for this node_id. If so, close the old WebSocket gracefully (try/except around `await old_conn.websocket.close()`), deregister the old connection.
c) Register the new connection in ConnectionManager.
d) Open a DB session. Upsert the Node record:
   - Use `await session.get(Node, payload.node_id)` to check if it exists
   - If exists: update `platform`, `version`, `projects` (store as list), `status = NodeStatus.connected`, `connected_at = now`, `last_heartbeat = now`, `last_seen = now`
   - If new: create Node with all fields, `first_seen = now`. Log warning: `"New node_id connected: %s"` (per CONTEXT.md decision)
e) Call `await reconcile_instances(payload.node_id, payload.running_instances, session)`
f) Commit the session.

**2. `async def reconcile_instances(node_id: str, node_running: list[InstanceSummary], session) -> None`**
Implements server-spec.md Section 6 exactly:

a) Build `node_ids = {s.instance_id for s in node_running}`
b) Query: `select(Instance).where(Instance.node_id == node_id, Instance.status.in_([InstanceStatus.pending, InstanceStatus.running]))`
c) Build `server_instances = {inst.instance_id: inst for inst in result.scalars()}`
d) `server_ids = set(server_instances.keys())`
e) **Lost instances** (in server but NOT in node): `for lost_id in server_ids - node_ids:` — set `status = InstanceStatus.errored`, `error = "lost: node reconnected without this instance"`, `finished_at = datetime.now(timezone.utc)`
f) **New instances** (in node but NOT in server): `for summary in node_running: if summary.instance_id not in server_ids:` — `session.add(Instance(instance_id=summary.instance_id, node_id=node_id, project=summary.project, session_id=summary.session_id, status=InstanceStatus.running))`
g) **Matched instances** (in both): `for summary in node_running: if summary.instance_id in server_instances:` — update `session_id` if changed, set `status = InstanceStatus.running`

Do NOT commit here — the caller (handle_node_register) commits.

**3. `async def handle_ack(payload: AckPayload, envelope_id: str) -> None`**
- Open DB session
- `instance = await session.get(Instance, payload.instance_id)`
- If instance and instance.status == InstanceStatus.pending: set `status = InstanceStatus.running`
- Commit
- Log: `"ACK received for instance %s (envelope %s)"` — note envelope_id is logged for correlation but not stored (per protocol-spec: ACK envelope ID = execute envelope ID)

**4. `async def handle_stream_event(payload: StreamEventPayload) -> None`**
- Parse the double-encoded data: `parsed_data = json.loads(payload.data)`
- Persist to DB:
  - Open session
  - Count existing events for this instance to determine sequence_num: `result = await session.execute(select(func.count()).select_from(StreamEventModel).where(StreamEventModel.instance_id == payload.instance_id))`; `seq = result.scalar() or 0`
  - `session.add(StreamEventModel(instance_id=payload.instance_id, sequence_num=seq, data=parsed_data, created_at=datetime.now(timezone.utc)))`
  - Commit
- Buffer in-memory: `connection_manager.append_stream_event(payload.instance_id, parsed_data)`

Import `func` from sqlalchemy: `from sqlalchemy import func, select, update`

**5. `async def handle_instance_started(payload: InstanceStartedPayload) -> None`**
- Open DB session
- `instance = await session.get(Instance, payload.instance_id)`
- If instance: set `session_id = payload.session_id`, `started_at = datetime.now(timezone.utc)`, `status = InstanceStatus.running` (in case ACK was missed)
- Commit

**6. `async def handle_instance_finished(payload: InstanceFinishedPayload) -> None`**
- Open DB session
- `instance = await session.get(Instance, payload.instance_id)`
- If instance: set `status = InstanceStatus.finished`, `exit_code = payload.exit_code`, `finished_at = datetime.now(timezone.utc)`
- Commit
- Clear in-memory stream buffer: `connection_manager.clear_stream_events(payload.instance_id)` (data already persisted to DB)

**7. `async def handle_instance_error(payload: InstanceErrorPayload) -> None`**
- Open DB session
- `instance = await session.get(Instance, payload.instance_id)`
- If instance: set `status = InstanceStatus.errored`, `error = payload.error`, `finished_at = datetime.now(timezone.utc)`
- IMPORTANT: This must work from BOTH `pending` AND `running` status (INST-07 rate-limit case: pending -> errored directly)
- Commit
- Clear in-memory stream buffer: `connection_manager.clear_stream_events(payload.instance_id)`

**8. `async def handle_node_disconnect(payload: NodeDisconnectPayload, node_id: str) -> None`**
- Open DB session
- Update Node: `status = NodeStatus.disconnected`, `last_seen = datetime.now(timezone.utc)`
- Commit
- Deregister from ConnectionManager: `connection_manager.deregister(node_id)`
- Log: `"Node %s disconnected gracefully: %s"` with reason

**9. `async def handle_unexpected_disconnect(node_id: str) -> None`**
- Open DB session
- Update Node record: `status = NodeStatus.disconnected`, `last_seen = datetime.now(timezone.utc)`
- Bulk-error all running/pending instances for this node in a single statement:
  ```python
  await session.execute(
      update(Instance)
      .where(Instance.node_id == node_id, Instance.status.in_([InstanceStatus.pending, InstanceStatus.running]))
      .values(status=InstanceStatus.errored, error="node disconnected unexpectedly", finished_at=datetime.now(timezone.utc))
  )
  ```
- Commit
- Deregister from ConnectionManager: `connection_manager.deregister(node_id)`
- Log: `"Node %s disconnected unexpectedly, errored all running instances"`

```python

    try:
        # ... operations ...
        await session.commit()
    except Exception:
        await session.rollback()
        raise
```

`async def node_ws_endpoint(websocket: WebSocket):`

**Step 1 — Pre-accept Bearer token validation (NODE-02, TOKN-01, TOKN-02):**
```python
settings = get_settings()
auth_header = websocket.headers.get("authorization", "")
token = auth_header.removeprefix("Bearer ").strip()
if not token or token not in settings.valid_tokens:
    await websocket.close(code=status.WS_1008_POLICY_VIOLATION)
    return
await websocket.accept()
```

**Step 2 — First frame must be node_register (NODE-03):**
```python
try:
    raw = await websocket.receive_text()
except WebSocketDisconnect:
    return
try:
    envelope = Envelope.model_validate_json(raw)
except Exception as exc:
    logger.warning("Invalid first frame: %s", exc)
    await websocket.close(code=status.WS_1003_UNSUPPORTED_DATA)
    return

if envelope.type != "node_register":
    logger.warning("First frame was %s, expected node_register", envelope.type)
    await websocket.close(code=status.WS_1003_UNSUPPORTED_DATA)
    return
```

**Step 3 — Parse and handle node_register:**
```python
try:
    register_payload = NodeRegisterPayload.model_validate(envelope.payload)
except Exception as exc:
    logger.error("Invalid node_register payload: %s", exc)
    await websocket.close(code=status.WS_1003_UNSUPPORTED_DATA)
    return

now = datetime.now(timezone.utc)
conn = NodeConnection(
    node_id=register_payload.node_id,
    websocket=websocket,
    platform=register_payload.platform,
    version=register_payload.version,
    projects=register_payload.projects,
    connected_at=now,
    last_heartbeat=now,
)
await handlers.handle_node_register(register_payload, conn)
node_id = register_payload.node_id
logger.info("Node %s registered (platform=%s, version=%s, projects=%s)",
            node_id, register_payload.platform, register_payload.version, register_payload.projects)
```

**Step 4 — Message dispatch loop:**
```python
try:
    while True:
        raw = await websocket.receive_text()
        # Update heartbeat on any received message (per RESEARCH.md Open Question 1 resolution)
        now = datetime.now(timezone.utc)
        connection_manager.update_heartbeat(node_id, now)

        try:
            envelope = Envelope.model_validate_json(raw)
        except Exception as exc:
            logger.warning("Node %s: malformed envelope: %s", node_id, exc)
            continue

        try:
            await dispatch_message(envelope, node_id)
        except Exception as exc:
            logger.error("Node %s: handler error for %s: %s", node_id, envelope.type, exc)
except WebSocketDisconnect:
    logger.info("Node %s: WebSocket disconnected", node_id)
    await handlers.handle_unexpected_disconnect(node_id)
except Exception as exc:
    logger.error("Node %s: unexpected error in message loop: %s", node_id, exc)
    await handlers.handle_unexpected_disconnect(node_id)
```

**Step 5 — dispatch_message function (separate from the endpoint):**
```python
async def dispatch_message(envelope: Envelope, node_id: str) -> None:
    msg_type = envelope.type
    payload_class = MSG_TYPES.get(msg_type)
    if payload_class is None:
        logger.warning("Node %s: unknown message type: %s", node_id, msg_type)
        return

    # Parse payload using the registered Pydantic model
    payload = payload_class.model_validate(envelope.payload or {})

    if msg_type == "node_register":
        # node_register after initial = status_request response
        # Need to create a fresh NodeConnection from existing
        existing = connection_manager.get(node_id)
        if existing:
            await handlers.handle_node_register(payload, existing)
    elif msg_type == "ack":
        await handlers.handle_ack(payload, envelope.id)
    elif msg_type == "stream_event":
        await handlers.handle_stream_event(payload)
    elif msg_type == "instance_started":
        await handlers.handle_instance_started(payload)
    elif msg_type == "instance_finished":
        await handlers.handle_instance_finished(payload)
    elif msg_type == "instance_error":
        await handlers.handle_instance_error(payload)
    elif msg_type == "node_disconnect":
        await handlers.handle_node_disconnect(payload, node_id)
    else:
        # Server-to-node types (execute, kill, status_request) should never arrive from node
        logger.warning("Node %s: received server-to-node type from node: %s", node_id, msg_type)
```

Key implementation details:
- Auth happens BEFORE `websocket.accept()` — closing before accept sends HTTP 403 (per research)
- `last_heartbeat` updated on ANY received message (resolves Open Question 1 from research — Starlette has no ping callback, so any message resets the stale timer)
- The node_register handler that fires during the message loop handles the `status_request` response case (node responds to status_request with another node_register per protocol-spec Section 3.2.3)
- handle_node_disconnect is called when node sends the graceful disconnect frame — but handle_unexpected_disconnect catches the WebSocketDisconnect exception for ungraceful drops
- Per-node asyncio.Lock is INSIDE handle_node_register (not in the dispatch loop) — the lock wraps only reconciliation, not the entire receive loop
