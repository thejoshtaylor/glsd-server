1. Create `backend/app/routers/transcribe.py`:
   - Imports: `logging` from stdlib; `APIRouter`, `HTTPException`, `UploadFile`, `File`, `status` from fastapi; `AsyncOpenAI` from openai; `CurrentUser` from `app.dependencies`; `get_settings` from `app.config`
   - Define `router = APIRouter(prefix="/api", tags=["transcribe"])`
   - Define constant: `MAX_AUDIO_BYTES = 25 * 1024 * 1024`  (25 MB)
   - Define `logger = logging.getLogger(__name__)`
   - Define endpoint:
     ```python
     @router.post("/transcribe")
     async def transcribe_audio(
         file: UploadFile = File(...),
         current_user: CurrentUser = None,
     ) -> dict[str, str]:
     ```
   - Step 1: Size validation BEFORE reading full content. Check `file.size` first (may be None):
     ```python
     if file.size is not None and file.size > MAX_AUDIO_BYTES:
         raise HTTPException(
             status_code=status.HTTP_413_REQUEST_ENTITY_TOO_LARGE,
             detail="Audio file exceeds 25 MB limit",
         )
     ```
   - Step 2: Read content, then validate actual length:
     ```python
     content = await file.read()
     if len(content) > MAX_AUDIO_BYTES:
         raise HTTPException(
             status_code=status.HTTP_413_REQUEST_ENTITY_TOO_LARGE,
             detail="Audio file exceeds 25 MB limit",
         )
     ```
   - Step 3: Call Whisper via AsyncOpenAI. Construct client per-request (do NOT use module-level global):
     ```python
     settings = get_settings()
     client = AsyncOpenAI(api_key=settings.openai_api_key)
     transcript = await client.audio.transcriptions.create(
         model="whisper-1",
         file=(file.filename or "audio.webm", content, file.content_type or "audio/webm"),
     )
     ```
   - Note: No `language` parameter — auto-detect per user decision in CONTEXT.md
   - Step 4: Return `{"text": transcript.text}`
   - Wrap the OpenAI call in try/except to catch `openai.APIError` and return a 502:
     ```python
     except Exception as exc:
         logger.error("Whisper transcription failed: %s", exc)
         raise HTTPException(
             status_code=status.HTTP_502_BAD_GATEWAY,
             detail="Transcription service failed",
         ) from exc
     ```
