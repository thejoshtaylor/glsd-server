**1. Password hashing utilities (module-level):**
```python
from pwdlib import PasswordHash
password_hasher = PasswordHash.recommended()

def hash_password(plain: str) -> str:
    return password_hasher.hash(plain)

def verify_password(plain: str, hashed: str) -> bool:
    return password_hasher.verify(plain, hashed)
```

**2. JWT token creation functions:**
```python
import hashlib
import uuid
from datetime import datetime, timedelta, timezone
import jwt
from app.config import Settings

def create_access_token(user_id: str, settings: Settings) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=settings.jwt_access_token_expire_minutes)
    payload = {"sub": user_id, "type": "access", "exp": expire}
    return jwt.encode(payload, settings.jwt_secret_key, algorithm=settings.jwt_algorithm)

def create_refresh_token(user_id: str, settings: Settings) -> str:
    expire = datetime.now(timezone.utc) + timedelta(days=settings.jwt_refresh_token_expire_days)
    payload = {"sub": user_id, "type": "refresh", "exp": expire}
    return jwt.encode(payload, settings.jwt_secret_key, algorithm=settings.jwt_algorithm)
```

**3. `register_user(email, password, db, settings)` -> TokenResponse:**
- Check if user with email already exists: `select(User).where(User.email == email)`. If exists, raise HTTPException 409 "Email already registered".
- Hash password with `hash_password(password)`.
- Generate `user_id = str(uuid.uuid4())`.
- Generate `team_id = str(uuid.uuid4())`.
- In a SINGLE transaction (the session already auto-commits/rollbacks via dependency):
  - `db.add(User(user_id=user_id, email=email, hashed_password=hashed))`
  - `db.add(Team(team_id=team_id, name=f"{email}'s Team", owner_id=user_id))`
  - `db.add(TeamMember(team_id=team_id, user_id=user_id, role="owner"))`
  - `await db.flush()` — to ensure all three are written atomically before token creation
- Create access and refresh tokens.
- Store refresh token hash: `hashlib.sha256(refresh_token_str.encode()).hexdigest()` in RefreshToken record.
- Return TokenResponse.

CRITICAL: User + Team + TeamMember MUST be created in the same transaction. If any fails, all roll back. This satisfies TEAM-01 atomically.

**4. `authenticate_user(email, password, db)` -> User | None:**
- `select(User).where(User.email == email)`, fetch one.
- If not found, return None.
- If `verify_password(password, user.hashed_password)` is False, return None.
- Return user.

**5. `store_refresh_token(user_id, token_str, settings, db)` -> None:**
- `token_hash = hashlib.sha256(token_str.encode()).hexdigest()`
- `expires_at = datetime.now(timezone.utc) + timedelta(days=settings.jwt_refresh_token_expire_days)`
- `db.add(RefreshToken(token_id=str(uuid.uuid4()), user_id=user_id, token_hash=token_hash, expires_at=expires_at))`

**6. `refresh_access_token(refresh_token_str, db, settings)` -> TokenResponse:**
- Decode JWT: `jwt.decode(refresh_token_str, settings.jwt_secret_key, algorithms=[settings.jwt_algorithm])`. Catch `InvalidTokenError` -> raise HTTPException 401 "Invalid or expired refresh token".
- Validate `type` claim is `"refresh"` and `sub` is present.
- Hash incoming token: `hashlib.sha256(refresh_token_str.encode()).hexdigest()`.
- Query DB: `select(RefreshToken).where(RefreshToken.token_hash == hash, RefreshToken.user_id == user_id, RefreshToken.revoked == False)`.
- If not found or `expires_at < now()`, raise HTTPException 401.
- Create new access token. Return TokenResponse with new access_token, same refresh_token.

**7. `revoke_refresh_token(refresh_token_str, db)` -> None:**
- Hash the token, find in DB, set `revoked = True`.

**8. `create_ws_ticket(user_id, db)` -> str:**
- Generate `ticket_id = str(uuid.uuid4())`.
- `expires_at = datetime.now(timezone.utc) + timedelta(seconds=30)`.
- `db.add(WsTicket(ticket_id=ticket_id, user_id=user_id, expires_at=expires_at))`.
- Return `ticket_id`.

**9. `validate_ws_ticket(ticket_id, db)` -> str | None:**
- Atomic query: `UPDATE ws_tickets SET used = True WHERE ticket_id = :id AND used = False AND expires_at > now() RETURNING user_id`. Use `text()` for raw SQL or equivalent SQLAlchemy approach.
- If no row returned, return None (ticket invalid, expired, or already used).
- Return `user_id` from the row.

CRITICAL for ws ticket: Use atomic UPDATE...WHERE...RETURNING to prevent replay race (Pitfall 4 from research). Do NOT use read-then-write pattern.

**1. Create `backend/app/routers/auth.py`:**

```python
from typing import Annotated
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
from app.config import Settings, get_settings
from app.dependencies import CurrentUser, DbSession
from app.schemas.auth import RegisterRequest, TokenResponse, RefreshRequest, WsTicketResponse
from app.services import auth_service

router = APIRouter(prefix="/api/auth", tags=["auth"])
```

Endpoints:

a) `POST /api/auth/register` — accepts `RegisterRequest` body, calls `auth_service.register_user(body.email, body.password, db, settings)`, returns `TokenResponse` with status 201.

b) `POST /api/auth/login` — accepts `OAuth2PasswordRequestForm` (via `Depends()`), calls `auth_service.authenticate_user(form_data.username, form_data.password, db)`. If None, raise HTTPException 401 with detail "Incorrect email or password" and header `WWW-Authenticate: Bearer`. Otherwise create access + refresh tokens via `auth_service.create_access_token` and `auth_service.create_refresh_token`, store refresh token via `auth_service.store_refresh_token`, return `TokenResponse`.

Note: `OAuth2PasswordRequestForm` uses `username` field per OAuth2 spec, but our users log in with email. The `username` field receives the email value. This is standard OAuth2 form behavior.

c) `POST /api/auth/refresh` — accepts `RefreshRequest` body, calls `auth_service.refresh_access_token(body.refresh_token, db, settings)`, returns `TokenResponse`.

d) `POST /api/auth/logout` — requires `CurrentUser` dependency (authenticated), accepts `RefreshRequest` body, calls `auth_service.revoke_refresh_token(body.refresh_token, db)`, returns `{"detail": "Logged out"}`.

e) `POST /api/auth/ws-ticket` — requires `CurrentUser` dependency, calls `auth_service.create_ws_ticket(current_user.user_id, db)`, returns `WsTicketResponse(ticket=ticket_id)`.

f) `GET /api/auth/me` — requires `CurrentUser` dependency, returns `{"user_id": current_user.user_id, "email": current_user.email}`. Simple identity check endpoint.
