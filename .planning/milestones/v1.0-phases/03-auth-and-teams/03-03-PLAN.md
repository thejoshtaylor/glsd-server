Create `backend/app/services/team_service.py` with the following functions:

**1. `create_team(name: str, owner_id: str, db: AsyncSession) -> Team`:**
- Generate `team_id = str(uuid.uuid4())`.
- Create `Team(team_id=team_id, name=name, owner_id=owner_id)`.
- Create `TeamMember(team_id=team_id, user_id=owner_id, role="owner")`.
- `db.add()` both, `await db.flush()`.
- Return the Team object.

**2. `list_user_teams(user_id: str, db: AsyncSession) -> list[Team]`:**
- `select(Team).join(TeamMember, Team.team_id == TeamMember.team_id).where(TeamMember.user_id == user_id)`.
- Return `list(result.scalars().unique())`.

**3. `get_team(team_id: str, user_id: str, db: AsyncSession) -> Team | None`:**
- Query Team joined with TeamMember where `team_id` matches AND `TeamMember.user_id == user_id`.
- Returns None if user is not a member of the team (access denied treated same as not found).

**4. `add_member(team_id: str, email: str, role: str, requesting_user_id: str, db: AsyncSession) -> TeamMember`:**
- Verify requesting user is owner of this team: `select(TeamMember).where(team_id, user_id=requesting_user_id, role="owner")`. If not owner, raise HTTPException 403 "Only team owners can add members".
- Look up target user by email: `select(User).where(User.email == email)`. If not found, raise HTTPException 404 "User not found".
- Check if already a member: `select(TeamMember).where(team_id, user_id=target.user_id)`. If exists, raise HTTPException 409 "User is already a team member".
- Validate role is "owner" or "member". If invalid, raise HTTPException 422 "Role must be 'owner' or 'member'".
- Create `TeamMember(team_id=team_id, user_id=target.user_id, role=role)`.
- `db.add(member)`, `await db.flush()`.
- Return the TeamMember.

**5. `list_team_members(team_id: str, user_id: str, db: AsyncSession) -> list[dict]`:**
- Verify user is a member of the team first (same access check pattern).
- Join TeamMember with User to get email: `select(TeamMember.user_id, User.email, TeamMember.role, TeamMember.joined_at).join(User, TeamMember.user_id == User.user_id).where(TeamMember.team_id == team_id)`.
- Return list of dicts with user_id, email, role, joined_at.

**6. `assign_node_to_team(team_id: str, node_id: str, requesting_user_id: str, db: AsyncSession) -> NodeTeam`:**
- Verify requesting user is owner of this team (same owner check as add_member). Raise 403 if not owner.
- Verify node exists: `await db.get(Node, node_id)`. If not found, raise HTTPException 404 "Node not found".
- Check if already assigned: `select(NodeTeam).where(node_id, team_id)`. If exists, raise HTTPException 409 "Node already assigned to this team".
- Create `NodeTeam(node_id=node_id, team_id=team_id)`.
- `db.add(assignment)`, `await db.flush()`.
- Return the NodeTeam.

**7. `list_team_nodes(team_id: str, user_id: str, db: AsyncSession) -> list[Node]`:**
- Verify user is a member of the team.
- `select(Node).join(NodeTeam, Node.node_id == NodeTeam.node_id).where(NodeTeam.team_id == team_id)`.
- Return `list(result.scalars().unique())`.

**8. `remove_member(team_id: str, target_user_id: str, requesting_user_id: str, db: AsyncSession) -> None`:**
- Verify requesting user is owner. Raise 403 if not.
- Cannot remove the last owner — check if target is the only owner. If so, raise HTTPException 400 "Cannot remove the last owner".
- Delete the TeamMember row.

Import all necessary models at the top: User, Team, TeamMember, Node, NodeTeam.

**1. Create `backend/app/routers/teams.py`:**

```python
from fastapi import APIRouter
from app.dependencies import CurrentUser, DbSession
from app.services import team_service
from app.schemas.teams import TeamCreate, TeamResponse, MemberAdd, MemberResponse, NodeAssign, NodeTeamResponse

router = APIRouter(prefix="/api/teams", tags=["teams"])
```

Endpoints — ALL require `CurrentUser` dependency:

a) `POST /api/teams` — accepts `TeamCreate` body, calls `team_service.create_team(body.name, current_user.user_id, db)`, returns `TeamResponse` with status 201.

b) `GET /api/teams` — calls `team_service.list_user_teams(current_user.user_id, db)`, returns `list[TeamResponse]`.

c) `GET /api/teams/{team_id}` — calls `team_service.get_team(team_id, current_user.user_id, db)`. If None, raise 404. Return `TeamResponse`.

d) `POST /api/teams/{team_id}/members` — accepts `MemberAdd` body, calls `team_service.add_member(team_id, body.email, body.role, current_user.user_id, db)`. Return `MemberResponse` with status 201. Construct MemberResponse from the returned TeamMember + the looked-up email.

e) `GET /api/teams/{team_id}/members` — calls `team_service.list_team_members(team_id, current_user.user_id, db)`. Returns `list[MemberResponse]`.

f) `DELETE /api/teams/{team_id}/members/{user_id}` — calls `team_service.remove_member(team_id, user_id, current_user.user_id, db)`. Returns 204 No Content.

g) `POST /api/teams/{team_id}/nodes` — accepts `NodeAssign` body, calls `team_service.assign_node_to_team(team_id, body.node_id, current_user.user_id, db)`. Returns `NodeTeamResponse` with status 201.

h) `GET /api/teams/{team_id}/nodes` — calls `team_service.list_team_nodes(team_id, current_user.user_id, db)`. Returns list of node objects (can use a simple dict response or define a NodeResponse schema — use `model_config = {"from_attributes": True}` pattern).
