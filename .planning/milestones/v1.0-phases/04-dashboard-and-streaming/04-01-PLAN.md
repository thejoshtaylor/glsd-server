   - `async broadcast_new_node_alert(node_id: str) -> None` — enqueue `{"type": "new_node_alert", "node_id": node_id}` to ALL connected frontend users (new nodes have no team assignment yet per DASH-07 research).
   - `async broadcast_instance_status(instance_id: str, status: str) -> None` — enqueue `{"type": "instance_status", "instance_id": instance_id, "status": status}` to all connections subscribed to that instance_id. Use `put_nowait()`.

async def user_can_access_instance(user_id: str, instance_id: str, db: AsyncSession) -> bool:
    result = await db.execute(
        select(TeamMember.user_id)
        .join(NodeTeam, TeamMember.team_id == NodeTeam.team_id)
        .join(Node, NodeTeam.node_id == Node.node_id)
        .join(Instance, Instance.node_id == Node.node_id)
        .where(TeamMember.user_id == user_id, Instance.instance_id == instance_id)
        .limit(1)
    )
    return result.scalar() is not None

**D. REST endpoints (routers/nodes.py):**

- `GET /api/nodes` — calls `list_nodes_for_user(current_user.user_id, db)`, returns `list[NodeResponse]`
- `GET /api/nodes/{node_id}` — calls `get_node_for_user(current_user.user_id, node_id, db)`, returns `NodeResponse` or 404
- `GET /api/instances` — calls `list_instances_for_user(current_user.user_id, db)`, optionally filter by `node_id` query param. Returns `list[InstanceResponse]`
- `GET /api/instances/{instance_id}` — query Instance by id, validate team access via `user_can_access_instance`, return `InstanceResponse` or 404

- `POST /api/instances/{instance_id}/kill` — accept `KillRequest` body (has `node_id`), call `dispatch_kill(body.node_id, instance_id, current_user.user_id, db)`. Return 200 `{"detail": "Kill dispatched"}`. Handle `PermissionError` as 403, `ValueError` as 400.

All endpoints require `CurrentUser` dependency. Use `DbSession` dependency. Router prefix: `/api`.
