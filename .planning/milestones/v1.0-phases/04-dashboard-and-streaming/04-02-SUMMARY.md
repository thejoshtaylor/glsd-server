## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] shadcn init failed: No Tailwind CSS config found**
- **Found during:** Task 1
- **Issue:** shadcn@latest init requires Tailwind CSS to already be discoverable AND a tsconfig path alias. Vite template doesn't include either out of the box.
- **Fix:** Wrote `vite.config.ts` with `@tailwindcss/vite` plugin and `resolve.alias` FIRST, updated `tsconfig.app.json` and `tsconfig.json` with `baseUrl` + `paths: { "@/*": ["./src/*"] }`, installed `@types/node` for `path.resolve`, then created `src/index.css` with `@import "tailwindcss"` — allowing shadcn init to detect both Tailwind v4 and the @ alias.
- **Files modified:** frontend/vite.config.ts, frontend/tsconfig.json, frontend/tsconfig.app.json, frontend/src/index.css
- **Commit:** 139a02d

**2. [Rule 1 - Deviation] CSS file: index.css vs main.css**
- **Found during:** Task 1
- **Issue:** Vite scaffolds `src/index.css`; shadcn init targets and updates that file. The plan specifies `src/main.css`.
- **Fix:** After shadcn init updated `src/index.css`, copied the complete content to `src/main.css` so main.tsx can import `./main.css` as specified. Both files exist; only `main.css` is imported by `main.tsx`.
- **Files modified:** frontend/src/main.css (created as copy of index.css)
- **Commit:** 139a02d
